# معامل صقر للتحاليل الطبية 🦅

موقع حجز زيارات منزلية لسحب عينات التحاليل الطبية — مع قائمة أسعار، واستلام نتائج أونلاين.

## المميزات

- 🏠 **حجز زيارة منزلية** لسحب العينة (بعد تسجيل حساب: الاسم + التليفون + العنوان)
- 🔑 تسجيل الدخول برقم التليفون وكلمة المرور
- 🆔 **رقم ملف تلقائي** لكل طلب معتمد (SQ-1001...) مع إشعار واتساب للعميل
- 💰 **قائمة أسعار** مع بحث فوري + رفع ملف Excel (يحذف تلقائياً الصفوف اللي سعرها صفر أو فاضي)
- 📄 **استلام النتائج** برقم الملف، ولوحة التحكم ترفع لينك النتيجة وتبعت إشعار واتساب
- ⚙️ **لوحة تحكم** مخفية في الفوتر (تحت خالص)
- 📱 تصميم متجاوب بالكامل (موبايل وكمبيوتر)

## التقنيات

- HTML / CSS / JavaScript (ملف واحد بدون سيرفر)
- SheetJS لقراءة ملفات Excel
- التخزين محلي (localStorage) — البيانات بتتحفظ في متصفح الجهاز

## طريقة الرفع على GitHub Pages

1. اعمل مستودع جديد (New Repository) — سمّه مثلاً `sakr-lab`
2. ارفع الملفات (upload files) أو بالأوامر:

```bash
git init
git add .
git commit -m "معامل صقر للتحاليل الطبية — v1"
git branch -M main
git remote add origin https://github.com/USERNAME/sakr-lab.git
git push -u origin main
```

3. من إعدادات المستودع: **Settings → Pages → Source: main branch → Save**
4. الموقع هيشتغل على: `https://USERNAME.github.io/sakr-lab/`

## لوحة التحكم

- الرابط في الفوتر تحت خالص: **⚙️ لوحة التحكم**
- كلمة المرور الافتراضية: `sakr2026` (غيّرها من الإعدادات + حط رقم واتساب المعمل)
